# Catatan Metodologi (bahan laporan)

> Instruksi: isi dokumen ini dengan bahasa sendiri sebelum sidang. Ini bahan
> utama bab metode dan pembahasan di laporan.

## 1. Mengapa CBR, bukan rule-based
(Isi: pengetahuan troubleshooting berbentuk pengalaman kasus; tidak perlu pakar
merumuskan aturan lengkap; bisa belajar lewat Retain; transparan lewat kasus rujukan.
Jangan klaim "lebih canggih", fokus ke kecocokan metode dengan domain.)

## 2. Representasi kasus
(Isi: struktur kasus, alasan lampu dipecah jadi gejala boolean, bukti lampu
diperlakukan sebagai atribut, bukan aturan.)

## 3. Pemilihan Jaccard dan Weighted Jaccard
(Isi: rumus, contoh hitung manual, alasan bobot, tabel bobot beserta justifikasi.)

## 4. Gejala tidak dipilih = False / tidak dilaporkan
(Isi: Jaccard mengabaikan pasangan 0-0; kelebihan dan kekurangannya; peran
opsi "Tidak tahu".)

## 5. Keterbatasan
(Isi: cakupan case base, sensitivitas terhadap bobot, kelemahan one-hot,
case base kecil.)
